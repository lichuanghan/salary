# 薪酬计算系统设计文档

**项目名称**: HR薪酬管理系统
**项目类型**: 本地桌面端应用
**创建日期**: 2026-03-12
**技术栈**: Tauri + React + TypeScript + SQLite

---

## 1. 项目概述

本系统是一个完整的本地桌面端HR薪酬管理工具，支持员工信息管理、工资结构配置、社保公积金计算、个人所得税计算以及考勤扣款补贴等核心功能。

### 1.1 核心功能

| 功能模块 | 描述 |
|---------|------|
| 工资结构配置 | 支持基本工资、岗位工资、绩效奖金、补贴等多维度工资项配置 |
| 社保公积金计算 | 按城市政策配置五险一金比例和基数，自动计算个人/企业部分 |
| 个人所得税计算 | 支持个税专项附加扣除、年度汇算清缴 |
| 考勤扣款/补贴 | 迟到、早退、请假扣款，加班费、餐补、交通补贴等 |

### 1.2 技术架构

- **前端**: React + TypeScript + Tailwind CSS
- **后端**: Rust (Tauri)
- **数据库**: SQLite (本地存储)
- **构建**: Tauri bundler

## 3. 核心计算逻辑

### 3.1 工资计算公式

```
应发工资 = 基本工资 + 岗位工资 + 绩效奖金 + 补贴 - 考勤扣款 + 加班费
```

### 3.2 社保公积金计算

```
个人社保 = 养老 + 医疗 + 失业 + 公积金
企业社保 = 养老 + 医疗 + 失业 + 工伤 + 生育 + 公积金

计算基数 = min(max(实际工资, 最低基数), 最高基数)
```

### 3.3 个税计算

```
应纳税所得额 = 应发工资 - 社保公积金 - 起征点 - 专项扣除
应纳税额 = 应纳税所得额 × 税率 - 速算扣除数
实发工资 = 应发工资 - 社保公积金 - 个税
```

## 6. 技术实现要点

### 6.1 Tauri配置
- 使用 `tauri-plugin-sql` 操作SQLite
- 窗口配置：最小尺寸 1024x768
- 支持系统托盘（可选）

### 6.2 数据安全
- SQLite文件本地存储
- 可选密码保护
- 定期备份提醒

### 6.3 性能考虑
- 分页加载大数据
- 懒加载非关键数据
- 本地计算避免网络延迟
